# Steps to run the API:
1. First install Java 17, maven and PostgreSQL

2. Download/Clone this repository and open it in a code editor, such as VS Code.

3. Open pgAdmin and create a PostgreSQL database with the name ```gym_membership_db```

4. Set the user env variable ```DB_PASSWORD``` to your PostgreSQL password. This application also uses the PostgreSQL username ```postgres```. 

5. In terminal of your project in VS Code, run: 

    ```mvn spring-boot:run``` where the application runs at port 8083
    

6. Import the ```gym-membership-and-session-booking-system-midterm.postman_collection.json``` file into Postman to test different API endpoints.
